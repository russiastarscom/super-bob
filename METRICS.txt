ЧТО ЭТО
  Подробная система телеметрии: игра собирает визиты игроков,
  а отдельная админ-панель показывает их наглядно:
    • ГДЕ игрок остановился — экран, уровень/мир и его название,
      позиция в уровне (%), собранные печати, счёт, монеты,
      жизни, волна арены, кооп-комната;
    • КОГДА ушёл — момент завершения визита и его причина:
      «закрыл игру», «ушёл из вкладки», «бездействовал»
      (5 минут без действий) или «обрыв» (сессия не завершилась);
    • ВЕРНУЛСЯ ли — каждый визит помечается «возврат», с номером
      сессии игрока и временем с прошлого визита; панель считает
      возвратность (retention) дней 1/7/30.

ФАЙЛЫ
  metrics.js  — телеметрия (подключается из supabase-config.js после
                конфига; при сбое метрики не могут сломать игру —
                все вызовы обёрнуты в try/catch).
  admin.html  — ОТДЕЛЬНАЯ админ-панель ПОД ПАРОЛЕМ: лежит рядом с
                index.html, открывается только по прямой ссылке
                …/admin.html. Кнопки «АДМИН» на титульном экране
                больше нет — игроки панель не видят (см. «ПАРОЛЬ»).
  supabase-schema.sql — таблицы кооп-комнат (rooms/games/game_moves)
                и телеметрии (player_sessions — визиты, player_events
                — события). Выполнить весь файл в Supabase SQL Editor
                один раз: Dashboard → SQL Editor → New query → вставить
                → Run. Блоки идемпотентны, повторный запуск безвреден.

ПАРОЛЬ АДМИН-ПАНЕЛИ
  admin.html при открытии показывает экран входа. Пароль по умолчанию:
      superbob2026
  ОБЯЗАТЕЛЬНО смените его. Как: откройте …/admin.html, войдите,
  нажмите F12 → Console и выполните (свой новый пароль в кавычках):
      await bob5AdminHashes('НОВЫЙ_ПАРОЛЬ')
  Панель напечатает два хеша. Откройте admin.html в редакторе и впишите
  их в константы PW_SHA256 и PW_FB (в начале скрипта). Сохраните файл.
  Пароль запоминается на время вкладки (sessionStorage): до закрытия
  вкладки повторно не спрашивается.
  Честное замечание: пароль в статической HTML-странице — замок от
  любопытных игроков, а не криптография (исходник открыт). Сама база
  метрик в Supabase читается публичным ключом проекта; строгий режим
  «читать только по логину» описан в конце supabase-schema.sql
  (блок «ХОЧЕТСЯ СТРОЖЕ») — включается в дашборде за пару шагов.

КАК СЧИТАЕТ
  Игрок получает анонимный случайный ID (localStorage, без логинов
  и паролей). Каждые 10 секунд снимок «где игрок сейчас»; каждые
  30 секунд — выгрузка в Supabase (тот же проект, что у коопа,
  ключ публичный по дизайну). В момент ухода — финальная выгрузка
  (fetch keepalive), поэтому «когда ушёл» фиксируется даже при
  закрытии вкладки. Параллельно всё копится в localStorage —
  панель работает и без сети (источник «Локально»).

ЕСЛИ SUPABASE ОТВЕЧАЕТ «HTTP 404»
  Это значит: таблицы телеметрии в проекте ещё не созданы — схема
  (supabase-schema.sql) не развёрнута. Раньше панель падала с красной
  ошибкой; теперь: источник автоматически переключается на «Локально»
  (данные этого браузера), вверху появляется янтарная подсказка с
  пошаговой инструкцией и кнопкой «Скопировать supabase-schema.sql»
  (работает, когда панель открыта с того же адреса, где лежит файл).
  Развёртывание: Supabase Dashboard → SQL Editor → New query → вставить
  весь supabase-schema.sql → Run → в панели нажать «Обновить». Источник
  «Supabase» включится сам, подсказка исчезнет. До развёртывания игра
  работает как обычно: телеметрия копится в localStorage и повторяет
  попытки выгрузки раз в 5 минут — как только таблицы появятся, данные
  начнут уходить в общую базу без каких-либо правок игры.

АДМИН-ПАНЕЛЬ
  Вкладки: Обзор (KPI: игроки, сессии, возвраты, средняя длина
  визита, активность по дням), Сессии (таблица: где остановился /
  когда ушёл / вернулся ли), Игроки (агрегат по игрокам),
  Воронка уровней (где бросают и максимальный прогресс; волны
  арены), Причины ухода (сколько и как долго играют до каждого
  типа ухода), Журнал событий (старты уровней, смерти, победы,
  печати, покупки, кооп-комнаты, смены экранов).
  Фильтры: источник (Supabase — все игроки / Локально — этот
  браузер), период (24 ч / 7 / 30 дней / всё), поиск по ID игрока.
  Автообновление каждые 20 с (включается после входа по паролю);
  «Экспорт CSV» — выгрузка сессий для Excel (разделитель «;», UTF-8 BOM).

СОБЫТИЯ, КОТОРЫЕ ПИШЕТ ИГРА

  (смены экранов), level_load, level_start, level_clear (звёзды,
  время, смерти), death, gameover, seal_get, arena_start,
  arena_end (волна, счёт, рекорд), arena_exit, shop_buy (покупки
  в магазине — обёртки Bank.buy/buyAcc/buyArt), coop (вход/выход
  в кооп-комнату, код). Задел на будущее: Metrics.ev('тип', {...}).
